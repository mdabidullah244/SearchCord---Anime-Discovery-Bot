SearchCord is a Discord application that allows the user to search up any Anime, Manga, Anime or Manga Character (using Jikan REST API), stores user information (using SQlite3) regarding what Anime they've watched, will watch, what Manga they read, will read, what Anime/Manga they plan on watching/reading, their favorite Anime/Manga, and how many hours they've spent watching Anime (this information is used to calculate how those hours translate into days, weeks, months, and years).
However as the first version, it is heavily unoptimized and a second version is a work in progress with substantial improvements regarding duplicated codes, if-statements, classes, cogs, databases, APIs, etc.
